# 野心工作法

入口：`SKILL.md`。版本：1.0.1。

这是把任务推进到实际成果的个人工作流。可直接说：

> 用野心工作法处理下面的任务，保留我的限制，读取实际材料并交付可验证的成果，不要只列计划。

本目录遵循 Agent Skills 的基础结构。安装路径和导入方式由使用的宿主决定；复制文件不等于已经安装或启用。

详细方法在 `references/playbook.md`，应用配方在 `references/applications.md`，来源及主题覆盖在 `references/sources.md`。`assets/prior-prompts.md` 是项目早期独立编写的提示词，不是原文全文；公开版不包含精读 PDF。`evals/test-cases.json` 是尚未运行的行为测试用例，不是测试通过报告。

没有预设外部账号、MCP 服务器、后台任务或软件安装动作。技能不能凭空获得工具和权限。
